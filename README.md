# os-lab
从零开始写操作系统，从 512 字节引导扇区到……（目标持续更新）

## 环境
- CentOS 7 / NASM / QEMU 2.0 / GDB

## 进度
- [x] 01 最小引导扇区：理解 org 0x7C00、引导签名 0xAA55
- [x] 02 键盘回显：int 16h、栈与 ds 初始化
- [x] 03 二级加载：int 13h、es:bx、内存布局规划
- [x] 04 保护模式：GDT、A20、远跳转
- [ ] 05 C 语言内核入口：kmain、链接脚本、栈切换
- [ ] 06 中断与异常：IDT、PIC、时钟中断
- [ ] 07 分页与虚拟内存：页目录、页表、CR3
- [ ] 08 物理内存管理：E820、页分配器
- [ ] 09 进程与多任务：PCB、上下文切换、时间片
- [ ] 10 系统调用：int 0x80、用户态入口
- [ ] 11 简易文件系统：FAT12、文件加载

## 里程碑
- M1 引导扇区 + 保护模式：完成 01 ~ 04
- M2 C 语言内核入口：完成 05
- M3 中断与异常：完成 06
- M4 分页与内存管理：完成 07 ~ 08
- M5 多任务与系统调用：完成 09 ~ 10
- M6 文件系统雏形：完成 11
